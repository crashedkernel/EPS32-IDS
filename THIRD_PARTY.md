# Third-party components

Dependencies are installed separately through the Arduino environment.

| Component | Use and license reference |
| --- | --- |
| Arduino-ESP32 | Espressif core and bundled SDK components. See the upstream license files. [Source](https://github.com/espressif/arduino-esp32) |
| LibSSH-ESP32 | ESP32 port of libssh. See the upstream `COPYING` and `BSD` files. [Source](https://github.com/ewpa/LibSSH-ESP32) |
| cJSON | JSON parsing bundled with the Espressif environment. [MIT license](https://github.com/DaveGamble/cJSON) |
| IANA time zone identifiers | Configuration names. The browser's Intl implementation performs display-time conversion. |

The project's MIT license applies to its own source. Dependency license obligations also apply.

GL.iNet firmware and APIs belong to their respective owners. This project is independent of GL.iNet and Espressif.
